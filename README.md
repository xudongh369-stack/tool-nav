## 收录原则

- 只收**官方渠道**。破解版、激活码、需要买号的资源站，一律不收。
- 每一条都实测过能打开。打不开的、证书过期的、域名失效的会清掉，不留死链。
- 优先收能免费用或者有免费额度的，纯付费的会标价格区间。
- 说明里写「需自备网络」的，指国内直接访问不稳，需要自备工具，不是链接有问题。
